# 🏢 Mims Convention Centre Website

A modern, professional website for Mims Convention Centre built with Next.js, featuring a stunning teal color scheme that matches the brand identity.

## 🎨 Design Features

- **Professional Teal Color Scheme** - Based on logo color #00AC9D
- **Modern UI/UX** - Clean, minimal design with smooth animations
- **Responsive Design** - Optimized for all devices and screen sizes
- **Interactive Gallery** - Auto-playing carousel with thumbnail navigation
- **Smooth Scrolling** - Seamless navigation between sections
- **Professional Typography** - Using Geist and Poppins fonts

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm, yarn, pnpm, or bun

### Installation

1. Clone the repository

```bash
git clone <repository-url>
cd frontend
```

2. Install dependencies

```bash
npm install
# or
yarn install
# or
pnpm install
```

3. Run the development server

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser
